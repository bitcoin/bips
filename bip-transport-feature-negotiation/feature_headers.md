
# Feature header allocations

This table lists the feature headers that various BIPs have
assigned or proposed for assignment.

Header | Feature | Proposal
------ | ------- | --------

No headers have been assigned so far. Headers 0 and 240 to 255 are
reserved by [the specification](../bip-transport-feature-negotiation.md#feature-headers)
and do not appear here.

Note that this table is not authoritative but instead is reflective
of the BIPs proposing the changes. If multiple BIPs make conflicting
assignments for feature headers, that may lead to multiple entries for
the same feature header in this table. BIPs that are in Draft status
may be included in the table, and as a result, the headers and features they
define may be changed in future.
